- [ ] **O035 — `ExtendedProgressBar` leaks owned `SolidBrush` instances when colors change**
  - **Priority / state:** Low / shared-control GDI resource ownership; SOURCE-CONFIRMED residual of historical F028.
  - **Finding:** Historical commit `77e4c2ad7f0f26904f9ea8aff89cd1ebabe39135` correctly added disposal for repeatedly recreated `TextGraphics`, but the current control still creates `new SolidBrush(value)` every time `DropShadowColor` or `ForeColor` is assigned without disposing the previously owned brush. `Dispose(bool)` disposes only `TextGraphics`; it does not dispose the final non-system `DropShadowBrush`/`TextBrush`. Repeated theme/color changes or repeated designer/runtime assignments therefore accumulate GDI-backed brush resources for the lifetime of the process.
  - **Evidence:** `Controls/ExtendedProgressBar.cs`: fields initialize to `SystemBrushes.ControlDark` / `SystemBrushes.ControlText`; `DropShadowColor.set` assigns `DropShadowBrush = new SolidBrush(value)` and `ForeColor.set` assigns `TextBrush = new SolidBrush(value)` with no prior disposal. `Dispose(bool)` only disposes `TextGraphics`. Historical F028 patch `77e4c2ad7f` changed graphics-context disposal and did not touch either brush.
  - **Audit rationale checkpoint:** System-owned brushes must not be disposed, while brushes created by this control must be. A repair should use explicit ownership (for example track whether the current brush was allocated, dispose it before replacement and on control disposal) rather than indiscriminately disposing `SystemBrushes`. Keep color/rendering behavior unchanged.
  - **Acceptance for patch pass:** Repeatedly change both colors thousands of times on a live control and measure process GDI object count/handles before and after GC; it must remain bounded. Verify initial system brushes are never disposed, the final owned brushes are disposed exactly once with the control, painting after each change remains correct, and handle recreation/theme/DPI changes do not resurrect disposed resources. Retain the existing `TextGraphics` regression from F028.
