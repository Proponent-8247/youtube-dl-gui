# youtube-dl-gui 3.3.0-2

> **Prerelease.** This uses the project's existing hyphenated preview-version convention. It is the first release prepared from the `Proponent-8247/youtube-dl-gui` fork.

## Highlights

- Completed an end-to-end correctness, security, lifecycle, and compatibility audit covering all 105 substantive behavioral source files in the review matrix.
- Hardened the self-updater protocol: sender/process/window binding, bounded IPC, malformed-packet rejection, synchronous acknowledgement, cancellation, replacement, and rollback are regression-tested with the actual compiled application and updater executables.
- Fixed the updater's bounded IPC reentrancy deadlock while retaining timeout and hung-target protection.
- Application update discovery now uses the `Proponent-8247/youtube-dl-gui` release collection for both stable and prerelease checks. Stable-only mode filters prereleases locally, so a new fork with no releases or no stable releases is handled as a normal no-update state instead of an exception.
- User-facing project links and fork-owned operational metadata, including the About-page GitHub links and downloadable-language metadata, now resolve to `Proponent-8247/youtube-dl-gui` rather than the upstream repository.
- Downloaded executables require authoritative SHA-256 verification; available Authenticode/catalog signatures are checked and invalid signatures are rejected.
- FFmpeg downloads require the publisher checksum, ZIP extraction is bounded, duplicate executable entries are rejected, and failed replacements preserve the prior installation.
- Language downloads are verified against the GitHub blob object identity before replacement.
- Remote thumbnail bytes are bounded and normalized through the isolated FFmpeg decoder path before GUI decoding.
- Child-process ownership, cancellation, timeout, output draining, and cleanup were hardened across download, probe, conversion, and tool-update paths.
- Batch-from-file work now participates in application shutdown tracking; link-file imports are atomic rather than partially mutating the queue on validation failure.
- Batch runs receive unique readable identities.
- Normal diagnostics redact URL credentials and sensitive values. Explicit raw provider diagnostics remain available with a warning that they may contain secrets.
- Full per-session console/log/raw-provider/queue history is retained before UI truncation and can be exported explicitly.

## Compatibility

- Windows / WinForms application targeting **.NET Framework 4.7.2**.
- Release builds require a compiler/MSBuild toolchain that supports the repository's configured **C# 12** language level.
- The application release asset must remain named `youtube-dl-gui.exe`; the updater derives that exact asset URL from the release tag.
- This release is versioned internally as `3.3.0-2`. The embedded updater retains its own `1.6.0` program version.

## Update-channel behavior

Application update checks enumerate `https://api.github.com/repos/Proponent-8247/youtube-dl-gui/releases` in both update modes. When prerelease/beta updates are enabled, prereleases are eligible; when they are disabled, prereleases are filtered locally and only stable releases are eligible.

This means an empty fork release feed and a prerelease-only feed are both valid states. Stable-only clients return a normal no-update result when no stable release exists, while beta-enabled clients can discover `3.3.0-2` after it is published. GitHub's `/releases/latest` endpoint may remain unavailable until the fork has a stable release, but the application no longer depends on that endpoint.

## Known limits / intentionally deferred work

- The Release-hidden experimental Extended Converter feature is not being completed or expanded as part of this release.
- Policy for a failure to attach a Windows Job Object remains deliberately deferred pending a product/operational decision.
- Persistent cross-session download history is not part of this release. The new history behavior is per-session archival/export only.
- The release executable is currently unsigned unless a signing step is supplied outside this repository; SHA-256 hashes remain mandatory publication metadata, and Windows may show normal warnings for an unsigned prerelease.
