- [ ] **O030 — Persisted window locations are not validated against the current monitor layout**
  - **Priority / state:** Low-Medium / UI availability and persistence correctness; SOURCE-CONFIRMED.
  - **Finding:** The custom persisted `Point.Valid` check only rejects coordinates containing the special minimized-window sentinel value `-32000`. Forms then apply saved locations directly with `StartPosition = Manual` without checking whether any meaningful portion of the restored window intersects `Screen.AllScreens`/working areas. After a monitor is removed, resolution/orientation changes, RDP topology changes, or the INI contains stale large coordinates, main/settings/batch/extended/archive/log/history windows can reopen fully outside the visible desktop and appear not to launch.
  - **Evidence:** `Config/Interfacing/Point.cs`: `Valid => X != Invalid.X && Y != Invalid.Y`. Multiple shipping forms, including `frmMain`, `frmSettings`, `frmBatchDownloader`, `frmBatchConverter`, `frmExtendedDownloader`, `frmArchiveDownloader`, `frmLog`, and `frmFileNameSchemaHistory`, restore a saved location when `.Valid` is true; no shared screen-intersection/clamping check is applied before assignment.
  - **Audit rationale checkpoint:** Negative coordinates are legitimate on multi-monitor desktops, so the correction must not simply reject negatives or force everything to the primary monitor. Restore should preserve a valid secondary-monitor position when that monitor still exists while recovering stale/off-screen rectangles to an accessible working area. Size restoration must be considered with location so an oversized window is not technically intersecting but unusable.
  - **Acceptance for patch pass:** Persist positions on primary, left/top negative-coordinate secondary, right/bottom secondary, then test after removing each secondary and after shrinking working areas/resolution. Inject extreme/stale coordinates and oversized dimensions. Assert restored windows retain valid current-monitor placement when possible and otherwise clamp/recenter enough of the title bar/client rectangle to remain accessible. Cover every form that persists location/size and minimized/maximized shutdown states.
