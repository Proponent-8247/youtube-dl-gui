# Userscripts
This markdown sheet, if any third-party user scripts are made, will display a grid of available userscripts for use with youtube-dl-gui.

If you created a userscript that works with youtube-dl-gui, be sure to open a pull-request adding it to the grid below.  
If you don't have a repo to host it, you can add it to the [addons folder within this repository](https://github.com/Proponent-8247/youtube-dl-gui/tree/remediation/whole-repo-20261016/Addons).

|Userscript|Author|Website(s) supported|
|-|-|-|
|[reddit downloader](https://raw.githubusercontent.com/Proponent-8247/youtube-dl-gui/a1b3109e41d06af733c58e330a6e43e884ce5060/Addons/reddit%20video%20download%20button.user.js)|me (murrty)|(old layout) reddit.com|

The Reddit script is pinned to the exact reviewed fork commit above. Automatic userscript updates are disabled: install future audited revisions manually after checking their changes. This avoids replacing the fork's permalink-only behavior with a mutable upstream version.
