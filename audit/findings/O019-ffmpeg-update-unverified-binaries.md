- [ ] **O019 — FFmpeg/FFprobe updates are installed without cryptographic verification**
  - **Priority / state:** High / executable supply-chain integrity; SOURCE-CONFIRMED.
  - **Finding:** `Updater.UpdateFfmpeg` downloads `https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip`, extracts `ffmpeg.exe` and `ffprobe.exe`, and transactionally replaces the configured binaries, but it never validates an expected SHA-256, publisher signature, detached signature, or signed manifest for the downloaded archive or extracted executables. HTTPS transport is therefore the only authenticity/integrity control before new executable code is installed and later launched by the application. This is distinct from the already-audited transactional rollback behavior.
  - **Evidence:** `youtube-dl-gui/Updater/Updater.cs`: `FfmpegDownloadLink` is a third-party ZIP; `UpdateFfmpeg` accepts `frmGenericDownloadProgress` success, opens the ZIP, locates `ffmpeg.exe`/`ffprobe.exe`, extracts them to `.update` files, then moves them into the live locations. No hash/signature verification occurs between download and installation.
  - **Audit rationale checkpoint:** TLS is necessary but does not provide an application-pinned artifact identity, and the same codebase already treats SHA-256 as mandatory for application updates. Because these downloaded files are executable dependencies, successful transport alone should not be conflated with release authenticity. A patch must use an authoritative verification source and must not invent a static hash for a moving `release-essentials.zip` URL.
  - **Acceptance for patch pass:** Define an authoritative integrity mechanism for the selected FFmpeg provider (for example, signed/versioned manifest or publisher signature). Test matching payload, modified archive, substituted executable inside an otherwise valid archive, missing/invalid verification metadata, cancellation, and rollback. Assert unverified binaries never replace the working pair and existing binaries remain usable after verification failure.
